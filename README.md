# RewardChain

A decentralized loyalty and rewards protocol with tier-based benefits and token incentives on Stacks blockchain.

## Features

- Multi-tier loyalty program creation with customizable rewards
- Stake-based enrollment system for customer commitment
- Points-based reward accumulation and redemption
- Cross-industry program support (Retail, Dining, Travel, Gaming)
- Transparent fee structure for platform sustainability

## Smart Contract Functions

### Public Functions
- `create-program` - Create a new loyalty program
- `enroll-in-program` - Enroll in program with stake
- `update-points-earned` - Update customer points balance
- `redeem-rewards` - Redeem accumulated rewards
- `deactivate-program` - Deactivate program (merchant only)

### Read-Only Functions
- `get-program` - Get program details
- `get-customer-enrollment` - Get customer's enrollment status
- `get-program-stats` - Get program statistics
- `get-platform-stats` - Get platform metrics

## Usage

Deploy the contract to create decentralized loyalty programs where merchants can reward customers with points and tokens for engagement and purchases.
